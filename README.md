# HabeshaTV

A Habesha-flavoured home screen for an Android TV stick: a ring of apps like a mesob (the woven
Ethiopian table basket), Amharic in Ge'ez script first with English beneath, the Ethiopian calendar
and clock (the big clock shows Ethiopian hours), and a still clock screensaver.

Target device: Xiaomi Mi Box S (`MIBOX4`, codename `oneday`), Android TV 9 (API 28), 32-bit ARM.

## Origin

This project starts from [Gathin23/cleanyourtv](https://github.com/Gathin23/cleanyourtv)
(MIT, commit `c1946b5`), a launcher that gives an Android TV a clean, Apple TV-style home.
The original licence and copyright notice are kept in [LICENSE](LICENSE). The Outfit typeface in the
launcher is under the SIL Open Font License 1.1 (`launcher/FONT-LICENSE-OFL.txt`).

Only the launcher, tools, themes and the Mi Box S reference lists were kept. The upstream CI
workflows, funding links and maintainer bots were left out on purpose.
